# Плата, дисплей и питание

Проверенная сборка: ESP32-S3, Flash 16 МБ, embedded PSRAM 8 МБ,
отдельная панель ST7789 240×320 по SPI. Конкретная модель dev-платы/модуля
не установлена; не подменяйте эти данные названием CYD или LILYGO.

Пины в обоих скетчах одинаковые:

```text
ESP32-S3               TFT ST7789
GPIO 42  ------------  SCL / SCK / CLK
GPIO 41  ------------  SDA / MOSI / DIN
GPIO 47  ------------  CS
GPIO 21  ------------  DC / A0
GPIO 14  ------------  RST / RES
GND      ------------  GND
```

Здесь SDA/SCL — надписи на **SPI-дисплее**, не I²C.
Чтение MISO не используется.

## Питание

ESP32-S3 использует логику **3,3 В**. Не подавайте на GPIO сигнал 5 В.
Питание VCC и подсветки BL/LED зависит от конкретной breakout-платы: есть
модули с регулятором и без него. Сначала проверьте маркировку/даташит своего
модуля. Не подключайте мощную подсветку к GPIO напрямую без проверки тока.
GND у дисплея и ESP32 должен быть общим. Перекоммутируйте обесточенную сборку.

При переходе с обычного монитора на офис проводка не меняется.

## Если не заработало

- **Чёрный экран:** питание подсветки, общий GND, CS/DC/RST, правильный порт.
- **Странные цвета:** проверьте контроллер; попробуйте `invertDisplay(true)`
  только если это требуется вашей панелью. Для проверенной панели — false.
- **Сдвинутая/повёрнутая картинка:** проверьте `init(240,320)` и `setRotation(1)`.
- **Сбой загрузки:** кабель должен передавать данные; закройте serial monitor.
  Попробуйте BOOT/RESET согласно инструкции платы и UploadSpeed=115200.
  Скорость 921600 на проверенной сборке не работала устойчиво.
- **Плата перезапускается:** проверьте питание и память. На проверенной сборке
  использован `esp32:esp32:esp32s3` со стандартными настройками, PSRAM Disabled.

Не прошивайте случайный подключённый ESP32: сначала определите порт нужной платы.
