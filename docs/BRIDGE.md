# Локальный мост

Мост `bridge.mjs` — Node.js 20+, встроенные модули, без npm-зависимостей.
Проверялся на macOS. Автозапуск, службу и глобальные плагины он не устанавливает.

## Переменные окружения

| Переменная | По умолчанию | Для чего |
|---|---|---|
| `HOST` | `auto` | Частный IPv4 выбранного интерфейса, перепривязка раз в 5 секунд; можно задать конкретный адрес |
| `LAN_INTERFACE` | `en0` | LAN-интерфейс при `HOST=auto` |
| `PORT` | `8787` | HTTP-порт, должен совпадать с BRIDGE_PORT в прошивке |
| `CODEX_SESSIONS_DIR` | `~/.codex/sessions` | Каталог rollout Codex |
| `CODEX_INDEX_FILE` | `session_index.jsonl` рядом с sessions | Индекс названий сессий |
| `OPENCODE_BIN` | `opencode` | Путь/команда OpenCode v2 |
| `STALE_MS` | `300000` | После тишины WORKING становится UNKNOWN, не DONE |
| `RETAIN_MS` | `1800000` | Окно начального обнаружения rollout Codex |

`auto` выбирает только RFC1918 IPv4: 10/8, 172.16/12, 192.168/16.
Не выбирает VPN-интерфейс автоматически. Без подходящего адреса мост ждёт сеть.
Явный `HOST` не валидируется как частный — не задавайте публичный адрес/0.0.0.0.

```sh
LAN_INTERFACE=en1 npm start
# Или для локальной проверки без доступа ESP32:
HOST=127.0.0.1 npm start
curl http://127.0.0.1:8787/api/agents
```

Единственный маршрут: `GET /api/agents`; остальные пути/методы получают 404.
Ответ содержит `agents` и `system`.

## mDNS

В `BRIDGE_HOST` укажите `scutil --get LocalHostName`, без `.local`.
ESP32 повторяет разрешение имени и сбрасывает адрес после HTTP-ошибки.
После смены DHCP-адреса прошивать ESP32 заново не нужно.

Если имя не находится: проверьте, что Mac и ESP32 в одной сети, отсутствуют
изоляция клиентов/гостевой режим, блокировка Bonjour/multicast и запрет входящих
соединений брандмауэра. После переименования Mac обновите BRIDGE_HOST.

## Источники и ограничения

Codex читает локальные файлы rollout; формат не является стабильным API.
WORKING: `event_msg.task_started`, DONE: `task_complete`, ERROR: `error`,
прерывание: UNKNOWN. Последняя активность обновляет свежесть; завершённые
записи сохраняются в памяти (до 80). Permission по паузе не угадывается.

OpenCode v2: `service status` проверяет уже работающий shared service,
затем `api get` читает locations, active sessions, permissions/forms и Session.Info.
Нужен v2 с этими API, а не произвольная версия CLI.
`outcome=succeeded/failed` учитывается только при `time.idle >= time.busy`.
После перезапуска моста старые завершённые сессии OpenCode могут не обнаружиться.
Содержимое сообщений через API монитора не отдаётся, локальные ответы не логируются.

Системная строка: `pmset -g batt`, `scutil --nc list` (только Happ),
GET `https://www.apple.com/library/test/success.html` раз в 30 секунд.
Это не проверка всей маршрутизации VPN или глобальной доступности интернета.
На других ОС соответствующие данные могут остаться UNKNOWN.

Опрос: Codex 2 секунды, OpenCode 3 секунды, TFT 2 секунды.
Длительность — время с подтверждённого начала задачи, не процент выполнения.
База данных не создаётся. Таймаут не доказывает, что агент завершил работу.
