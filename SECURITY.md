# Безопасность и приватность

- Используйте мост только в доверенной локальной сети. HTTP не зашифрован,
  аутентификации нет. Не делайте port forwarding, публичный туннель или запуск
  на публичном интерфейсе. Устройства в этой сети могут прочитать метаданные.
- Названия проектов/чатов, ID сессий, статусы, время и системная сводка уходят
  на TFT по LAN. Полные пути исключаются из публичного API. Промпты, команды
  и ответы не возвращаются API, но сами названия чатов тоже могут быть личными.
- `config.h` с SSID/паролем остаётся локально. Не загружайте его в Issues,
  скриншоты редактора, архивы, Releases или gist. Бинарная прошивка монитора
  и дамп Flash тоже могут содержать пароль, поэтому не публикуйте их.
- Проверка интернета обращается к Apple; метаданные агентов не передаются.
- Все сообщения и API внешних инструментов считаются недоверенными данными.
  Мост предназначен для read-only наблюдения, не запускает команды из названий
  чатов или rollout и не меняет глобальные настройки агентов.

Если заметили утечку, не прикладывайте секреты к публичному Issue. Сначала
отзовите/смените секрет и свяжитесь с автором через контакты профиля GitHub.
